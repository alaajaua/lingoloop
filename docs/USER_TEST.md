# 단어 암기 사용성 테스트

2026-10-05 사용자 요청에 따라 온보딩보다 핵심 암기 흐름의 사용성 검증을 우선합니다. 검색은 보조 기능이며 관리자 CMS와 사용자 학습 화면은 구분합니다.

## 현재 테스트 범위

모바일 웹 /practice: 예시 5개 바로 풀기(먼저 익히기는 선택) → 예문 빈칸 회상 → 정답/오답 피드백 → 오답 및 힌트 사용 단어 재시도. 로그인 없이 체험할 수 있습니다. 고정 예시를 사용하며 CMS 초안을 공개하지 않습니다. 결과는 메모리에만 있고 새로고침하면 초기화됩니다. 정식 서버 채점, 학습 이력, SRS, 추천은 아직 구현 전입니다. Phase 5~9 완료로 간주하지 않습니다.

## 사용자에게 요청할 행동

1. 별도 설명 없이 바로 문제 풀기를 시작합니다. 먼저 익히기는 원하는 경우에만 선택합니다.
2. 답을 입력하고, 막히면 힌트 또는 모르겠어요를 사용합니다.
3. 결과를 보고 어려운 단어를 다시 연습합니다.
4. 10분 뒤 화면 없이 기억나는 단어와 뜻을 말합니다. 이는 작은 탐색 테스트이며 장기 암기 효과를 입증하지 않습니다.

## 관찰할 것

- 시작 방법과 다음 행동을 스스로 찾는가?
- 단어 자체를 몰랐는지, 예문의 문법 형태 때문에 틀렸는지? meet/met을 별도로 확인합니다.
- 오답 피드백이 이해되고 재시도로 이어지는가?
- 입력 부담 때문에 포기하는가?

실제 사용자 반응은 아직 수집하지 않았습니다. 자동 동작 검증을 사용자 테스트 결과로 대체하지 않습니다.

## 다음 결정

피드백을 받아 암기 방식을 조정한 뒤, 서버 기반 학습 세션/채점/기록과 복습 일정을 연결합니다. 기존 BUILD_PLAN 순서는 이 사용성 검증을 먼저 수행하는 것으로 조정하며, 나머지 단계는 유지합니다.

## 구현 검증

2026-10-05: 모바일 타입 검사, 변경 파일 lint, 채점 및 재시도 대상 테스트 2개 통과. 브라우저에서 카드 5개 → 정답/힌트/모르겠어요 → 결과 3/5 → meet와 book 재시도 → 5/5 완료를 확인했습니다. 사용자 체험을 위해 시작 화면으로 복귀했습니다. 이는 기능 검증이며 실제 사용자 피드백은 대기 중입니다.

사용자 피드백 반영: 이미 아는 단어의 선행 학습을 강제하지 않습니다. 기본 시작은 바로 문제 풀기이며, 먼저 익히기는 보조 선택으로 제공합니다.
