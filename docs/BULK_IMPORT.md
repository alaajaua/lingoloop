# 단어 대량 등록 안내

관리자 화면의 **CSV / TSV 대량 등록**에서 사용합니다.

1. CSV 템플릿 또는 작성 예시를 내려받습니다.
2. 항목을 작성하고 UTF-8 CSV 또는 TSV로 저장합니다. Excel 파일(.xlsx)은 CSV UTF-8로 내보내세요.
3. 파일을 선택하고 **파일 검증 및 미리보기**를 누릅니다.
4. 행별 오류와 중복, 실제 저장할 내용을 확인합니다.
5. **정상 N행을 초안으로 등록**을 누릅니다. 완료 후 목록에서 확인하고 검토/게시를 진행합니다.

한 번에 헤더를 제외한 최대 500행, 최대 1MiB를 지원합니다. 한 행은 단어 1개와 의미 1개, 예문 최대 1개입니다. 추가 의미와 예문은 저장 후 편집합니다.

## 입력 항목

헤더는 아래 영문 이름을 그대로 사용합니다. 필수 열은 반드시 포함하고, 선택 열은 생략할 수 있습니다.

| 열 | 필수 | 내용 |
|---|---|---|
| lemma | 예 | 기본형, 최대 100자 |
| displayWord | 예 | 표시 단어, 최대 100자 |
| partOfSpeech | 예 | 품사, 예: noun, verb |
| difficulty | 예 | 단어 난이도 1~30 |
| meaningKo | 예 | 한국어 의미 |
| definitionEn | 아니요 | 영어 정의 |
| frequencyRank | 아니요 | 1 이상의 정수 |
| tags | 아니요 | 태그를 파이프 문자로 구분, 예: daily|travel |
| sentenceEn | 조건부 | 영어 예문 |
| sentenceKo | 조건부 | 예문 번역 |
| targetForm | 조건부 | 예문 속 정답 형태 |
| exampleDifficulty | 조건부 | 예문 난이도 1~30 |
| explanation | 아니요 | 예문 설명 |
| audioUrl | 아니요 | HTTPS 오디오 주소 또는 등록된 /audio/ 파일 경로 |

예문 관련 값을 하나라도 입력하면 sentenceEn, sentenceKo, targetForm, exampleDifficulty가 모두 필요합니다. 빈 난이도를 임의 값으로 채우지 않습니다. 예문 없이 초안 등록은 가능하지만 이후 검토/게시 조건은 별도로 충족해야 합니다.

## 오류와 중복 처리

- 기본형의 앞뒤 공백과 대소문자를 정규화하고 품사를 함께 비교합니다. 기존 단어와 같으면 보관 상태를 포함해 제외합니다.
- 파일 안에서 같은 기본형과 품사가 반복되면 해당 행을 모두 제외합니다. 자동 병합하거나 기존 단어를 덮어쓰지 않습니다.
- 행별 입력 오류는 미리보기에 표시하고 정상 행만 저장합니다.
- 잘못된 따옴표, 열 개수, 알 수 없는 헤더, 크기 초과 등의 파일 구조 오류는 파일 전체를 거절합니다.
- CSV 값에 쉼표나 줄바꿈이 있으면 따옴표로 감싸고, 값 내부 따옴표는 두 번 적습니다. UTF-8 BOM을 지원합니다.
- 화면의 행 번호는 헤더 다음 레코드부터 2로 셉니다. 값 내부에 줄바꿈이 있으면 편집기의 물리적 줄 번호와 다를 수 있습니다.

저장 직전에 다시 검사합니다. 미리보기 이후 중복 상태 등이 바뀌면 다시 검증해야 합니다. 정상 행은 한 번에 저장하며, 저장 도중 오류가 나면 이번 등록 전체를 취소합니다. 동일 등록 요청을 재시도해도 중복 생성하지 않습니다. 모든 등록 결과는 초안이며 작업 이력에 파일 등록으로 기록합니다.
