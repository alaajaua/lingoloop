# 15. Interaction Timing

## Question
- screen rendered → timer starts
- answer submit → button loading
- response → feedback 150–200ms transition

## Feedback
- next button immediately enabled
- next question can be prefetched

## Session Complete
- 300ms success motion
- stats count-up optional, max 600ms

---

# 16. Layout Rules

- Screen padding: 20
- Learning content max width: 640
- CTA bottom safe-area aware
- keyboard open 시 CTA가 키보드 위로 이동
- Home/Progress는 scroll 가능
- Learning은 가능하면 single viewport
